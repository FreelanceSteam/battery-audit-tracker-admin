BATTERY AUDIT TECHNICIAN LAUNCHER

Upload the complete contents of this folder into:
battery-audit-tracker-admin/install/

GitHub Pages URL:
https://freelancesteam.github.io/battery-audit-tracker-admin/install/

Unique technician launcher link format:
https://freelancesteam.github.io/battery-audit-tracker-admin/install/?token=TECHNICIAN_TOKEN

IMPORTANT:
- Replace TECHNICIAN_TOKEN with the existing token for that technician.
- Do not share one technician's token with another technician.
- This launcher stores the token in that browser's local storage for Home Screen relaunch.
- The Open Battery Audit button forwards the token to the existing Apps Script web app.
- Existing Code.gs, audit data, and Technician Links sheet do not need to be changed for this launcher.
- On iPhone: open the unique launcher link in Safari > Share > Add to Home Screen.
- On Android/Chrome: open the unique launcher link > browser menu > Install app / Add to Home screen.
